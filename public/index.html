How the delay is added

Same as the Type menu on the Control tab. Used by the dock, hotkeys and Stream Deck. Removing the delay jumps back to live, or speeds up gradually in Gradual mode.

Where to stream

Twitch: rtmp://live.twitch.tv/app. YouTube: rtmp://a.rtmp.youtube.com/live2. Kick: the rtmps:// URL from your Kick dashboard. Keys are stored only in config.json on this computer.

Delay options

How much of the stream Rewind can replay. About 45 MB of memory per minute at 6000 kbps.

OBS control (optional)

Showing or hiding a source with this name in OBS toggles the delay. See Setup, Hotkeys.

1. Point OBS at Delay Bridge

Using the OBS plugin? Click Use Delay Bridge with my … settings on the Control tab. It copies your server and key from OBS and points OBS here. Otherwise:

  1. OBS, Settings → Stream, Service: Custom…
  2. Server:
    Stream Key: anything (e.g. live)
  3. Settings → Output: set Output Mode to Advanced, then Keyframe Interval to 2 s.
  4. Turn off OBS's own Stream Delay (Settings → Advanced).
  5. Add your Twitch/YouTube/Kick key in Settings here, then start streaming in OBS as usual.

The OBS plugin adds it for you. Without the plugin: OBS, Docks → Custom Browser Docks, name it "Delay", URL:

3. Hotkeys

With the OBS plugin: OBS, Settings → Hotkeys, type Delay Bridge in the filter, and set keys for Toggle delay, Turn on delay, Remove delay and Add 5 minutes.

Standalone program (needs OBS control on in Settings): add an empty Text source named Delay Toggle to your main scene. In OBS Settings → Hotkeys, give both "Show 'Delay Toggle'" and "Hide 'Delay Toggle'" the same key. Each press toggles the delay.

Stream Deck: use the built-in Website action with "GET request in background" ticked:

Parameters: seconds, minutes (turn off after), mode=gradual|rewind|instant|overlay. Works with Bitfocus Companion, AutoHotkey, Touch Portal and more.
