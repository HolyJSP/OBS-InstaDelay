1 · Point OBS at Delay Bridge

Using the OBS plugin? Just click Use Delay Bridge with my … settings on the Control tab — it copies your server and key from OBS and points OBS here. Otherwise:

  1. OBS → Settings → Stream → Service: Custom…
  2. Server:
    Stream Key: anything (e.g. live)
  3. Settings → Output: set Output Mode to Advanced, then Keyframe Interval to 2 s (or 1 s). Delay changes snap to keyframes.
  4. Turn off OBS's own Stream Delay (Settings → Advanced).
  5. Add your Twitch/YouTube/Kick key in Settings here, then press Start Streaming in OBS as usual.

3 · Hotkeys

With the OBS plugin: OBS → Settings → Hotkeys → type Delay Bridge in the filter → set keys for Toggle delay, Turn on delay, Remove delay and Add 5 minutes.

Standalone program (needs OBS control on in Settings): add an empty Text source named Delay Toggle to your main scene. In OBS Settings → Hotkeys, give both "Show 'Delay Toggle'" and "Hide 'Delay Toggle'" the same key. Each press toggles the delay using your defaults.

Stream Deck: use the built-in Website action with "GET request in background" ticked:

Parameters: seconds, minutes (auto-off), mode=instant|overlay. Works with Bitfocus Companion, AutoHotkey, Touch Portal, etc.
